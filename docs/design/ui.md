# 画面と操作の設計（v0.1）

各ハーネスのよいところを組み合わせる。参考にするのは考え方だけで、コードや文言は写さない。DSH（deepseek-ai/deepseek-harness）の画面は Web なので、画面の作りではなく操作の考え方を借りる。

| 取り入れるもの | 参考にしたハーネス |
| --- | --- |
| 会話が端末に流れ、履歴に残る画面 | Claude Code、Codex CLI |
| 文脈の割合・トークン・料金を常に見せる | OpenCode（横の欄）、DSH（やりとりごとのトークン） |
| 「質問」「計画」「実行」のモードを Shift+Tab で回す | Cursor CLI |
| モードとは別に、確認なしで許す範囲を選ぶ（`/permission`） | DSH、Codex CLI |
| Enter で今回だけ許可、Esc で却下、常に許可は明示して選ぶ | DSH |
| 計画を1つの文書として見せ、承認してから実装する | DSH |
| 変更を差分で見せ、まとまりごとに採用か却下を選ぶ／元に戻す | Cursor |
| やりとりの変更をあとからファイルごとに見直す（Ctrl+R） | Cursor CLI |
| 動いている間に打った指示を待たせて、次の区切りで渡す | DSH |
| 途中経過（推論・道具の行）の見せ方を切り替える | DSH |
| `/model` でモデルと推論の量（effort）を選ぶ | DSH |
| `@` でファイル指定、`/` コマンド、Esc で止める、文脈の内訳を見る | Claude Code、DSH |
| ↑で前の入力、Shift+Enter／Ctrl+J で改行、Ctrl+D 2回で終了 | Cursor CLI |

## 画面
会話は上から下へ流れ、終わったものは端末の履歴に残る。いちばん下に入力欄と、状態の行を1行置く。

```
› src/app.ts のエラー処理を直して

  ● src/app.ts を読みました（120行）
  ● 編集の案: src/app.ts（1/2）
    - if (err) return;
    + if (err) throw new AppError("読み込みに失敗しました", { cause: err });
    Enter 採用  Esc 却下  a このファイルは全部採用  e 却下して理由を伝える

  直しました。読み込みの失敗を AppError として投げるようにしています。
  （今回 4.1k トークン・0.0004ドル）

┌──────────────────────────────────────────────────────────────┐
│ ›                                                            │
└──────────────────────────────────────────────────────────────┘
 実行  確認する  deepseek-v4.1-flash（high）  文脈 12%（15.3k/128k）  合計 0.003ドル
```

- 状態の行: モード、権限、モデルと effort、文脈の使用量（割合と数）、セッションの料金の合計
- やりとりが終わるたびに、そのやりとりのトークンと料金を1行で出す
- 道具を使った行は1行にまとめ、中身は必要なときだけ広げる（読んだファイルの全文は出さない）
- 文字の幅は全角を2として数え、日本語でも枠や表がずれないようにする

## モード
Shift+Tab で「実行 → 計画 → 質問」の順に回す（`/mode` でも選べる）。今のモードは状態の行の先頭に出す。

| モード | すること |
| --- | --- |
| 実行（既定） | 読む・探す・編集・シェル。確認するかは権限で決まる |
| 計画 | 読む・探すだけで、編集はしない。最後に計画を1つの文書にまとめて出す（下の「計画の見直し」） |
| 質問 | 読む・探すだけで答える。編集もシェルもしない |

モードの違いは道具の定義を変えずに、会話の末尾に足す短い指示で伝える（キャッシュを壊さないため。`context.md` の「キャッシュを壊さない決まり」）。計画と質問のモードで編集やシェルが呼ばれたら、ハーネスが断ってモデルに返す。

## 権限
確認なしで許す範囲を `/permission` で選ぶ。モードとは別に持ち、状態の行に出す。

| 権限 | 編集（作業フォルダの中） | シェル |
| --- | --- | --- |
| 確認する（既定） | 差分を見せて、まとまりごとに確認 | 毎回確認 |
| 編集は自動 | 確認せず適用（Ctrl+R で見直し、`/undo` で戻せる） | 毎回確認 |
| すべて自動 | 確認せず適用 | 確認せず実行 |

- 「すべて自動」を選ぶときは、危険を説明して、もう一度確かめる
- 作業フォルダの外への書き込みは、どの権限でも確認する
- 起動時の既定は設定ファイルで変えられる。`/permission` はそのセッションだけを変える

## 承認
シェルの実行や、作業フォルダの外への書き込みを確かめるとき:
- Enter で今回だけ許可、Esc で却下
- 「このセッションでは同じコマンドを常に許可」は、`a` を押して選んだときだけ（Enter では常に許可にならない）
- 却下したら、モデルに「利用者が断った」と返す。`e` で理由を書いて返すこともできる

## 変更の確認と元に戻す
- 編集は、適用する前に差分で見せる（権限が「確認する」のとき）。まとまり（hunk）ごとに Enter 採用、Esc 却下、`a` そのファイルは全部採用、`e` 却下して理由を伝える、を選ぶ。却下と理由は、そのままモデルに返す
- Ctrl+R で、今のやりとりで変えたファイルを見直す画面を開く。←→ でファイルを切り替え、↑↓ で読み進める。`i` で、見直しながら追加の指示を書いて送れる
- やりとりを始める前に、そのやりとりで触るファイルの元の状態を残す（チェックポイント）。`/undo` で直前のやりとりの変更を戻し、`/undo 3` で3つ前まで戻す。git の作業ツリーには手を加えない

## 計画の見直し
- 計画モードでは、モデルが最後に計画を1つの文書にまとめる。ハーネスはそれを `.ja-harness/plans/<日時>.md` に保存し、画面に見せる
- 選べるのは、「承認して実行」（実行モードに切り替えて、計画に沿って始める）、「直す」（理由を書いて計画を直させる）、「却下」の3つ
- 承認した計画は、実行のあいだ会話に残る。要約するときも計画の文書のパスを残す

## 動いている間の入力
- モデルが作業している間も入力できる。送った文は待ち行列に入り、状態の行に「待ち 1件」と出す
- 次の区切り（道具の結果を返したあと）で、利用者の発言として会話の末尾に足す。会話の末尾に足すだけなので、キャッシュは壊れない
- 待ち行列の文は、渡す前なら ↑ で呼び戻して書き直せる
- Esc で作業そのものを止める（待ち行列の文は残す）

## 途中経過の見せ方
`/details`（または Ctrl+O）で切り替える。

| 見せ方 | 推論 | 道具の行 |
| --- | --- | --- |
| 簡潔（既定） | 隠す（考えている間は「考えています…」の1行） | 1行にまとめる |
| 詳しく | 先頭の数行を見せる | 引数と結果の先頭を見せる |

どちらでも、モデルの答えは隠さない。

## 入力
- 日本語入力（IME）で変換を確定する Enter では送信しない。送信は、変換していない状態での Enter
- 改行は Shift+Enter。端末が区別できないときは Ctrl+J
- ↑↓ で前に送った入力をたどる
- `/` と `@` で候補を出す。`/` はコマンド、`@` は作業フォルダのファイル。選んだファイルは中身をそのまま入れず、パスだけを渡してモデルに読ませる（文脈を節約するため）
- Esc で、モデルの返事や道具の実行を止める。2回続けて押すと、直前の入力を書き直せる
- Ctrl+C は入力欄を空にする。Ctrl+D を2回で終了する

## `/` コマンド（v0.1）
| コマンド | すること |
| --- | --- |
| `/help` | 使い方とキー操作 |
| `/mode` | モードを選ぶ（Shift+Tab と同じ） |
| `/permission` | 権限を選ぶ |
| `/model` | モデルと effort を選ぶ。次のリクエストから効く（動いている途中の1回は、始めたときのまま）。一覧に、実績の課題1つあたりの料金と往復の数を出す。参考に、入力・出力の単価と日本語1文字あたりの料金も出す。モデルを変えるとキャッシュが効かなくなることを、その場で知らせる |
| `/context` | 文脈の内訳（指示、道具の定義、MCP、会話、道具の結果、隠した分）をトークンで見せる |
| `/details` | 途中経過の見せ方を切り替える |
| `/undo` | 変更を戻す |
| `/resume` | 保存したセッションの一覧から選んで続ける |
| `/clear` | 会話を空にして始め直す（セッションは保存しておく） |
| `/compact` | 今すぐ会話を要約して短くする（`/summarize` でも同じ） |

## 言語
画面の文は `language.ui`（既定 `ja`）で切り替える。文は1か所にまとめ、言語ごとのファイルから読む。全角の幅を2として数える処理は、どの言語でも同じに使う。

## セッションの保存
- やりとりの記録を `~/.ja-harness/sessions/<日時>-<作業フォルダ名>.jsonl` に1行ずつ書く。usage と料金も一緒に残す（あとでトークンを測れるように）
- `/resume`、起動時の `--resume <id>`（指定したもの）と `--continue`（いちばん新しいもの）で続きから始める

## まだ決めていないこと
- 画面を描く道具（Ink のような React 風の部品か、標準の readline を土台に自作するか）。日本語入力と全角の幅の扱いを試してから決める。DSH の画面は Web（React）なので、ここは参考にならない
