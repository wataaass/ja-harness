# 画面と操作の設計（v0.1）

各ハーネスのよいところを組み合わせる。参考にするのは考え方だけで、コードや文言は写さない。DSH は URL を受け取ってから足す。

| 取り入れるもの | 参考にしたハーネス |
| --- | --- |
| 会話が端末に流れ、履歴に残る画面 | Claude Code、Codex CLI |
| 文脈の割合・トークン・料金を常に見せる | OpenCode（横の欄） |
| 「計画」と「実行」を切り替える | OpenCode、Claude Code |
| 承認の段階をはっきり分ける | Codex CLI |
| 変更を差分で見せ、採用か却下を選ぶ／元に戻す | Cursor |
| `@` でファイル指定、`/` コマンド、Esc で止める、文脈の内訳を見る | Claude Code |

## 画面
会話は上から下へ流れ、終わったものは端末の履歴に残る。いちばん下に入力欄と、状態の行を1行置く。

```
› src/app.ts のエラー処理を直して

  ● src/app.ts を読みました（120行）
  ● 編集の案: src/app.ts
    - if (err) return;
    + if (err) throw new AppError("読み込みに失敗しました", { cause: err });
    採用しますか？ [y] 採用  [n] 却下  [a] このファイルは全部採用

  直しました。読み込みの失敗を AppError として投げるようにしています。

┌──────────────────────────────────────────────────────────────┐
│ ›                                                            │
└──────────────────────────────────────────────────────────────┘
 実行・確認  deepseek-v4.1-flash  文脈 12%（15.3k/128k）  今回 4.1k  合計 0.003ドル
```

- 状態の行: モード、モデル、文脈の使用量（割合と数）、直前のやりとりのトークン、セッションの料金の合計
- 道具を使った行は1行にまとめ、中身は必要なときだけ広げる（読んだファイルの全文は出さない）
- 文字の幅は全角を2として数え、日本語でも枠や表がずれないようにする

## モード
Shift+Tab で順に切り替える。今のモードは状態の行の先頭に出す。

| モード | 読む・探す | 編集 | シェル |
| --- | --- | --- | --- |
| 計画 | 自動 | しない（案だけ出す） | 読むだけのもの（`ls`、`git status` など）に限り確認して実行 |
| 実行・確認（既定） | 自動 | 差分を見せて確認 | 毎回確認 |
| 実行・編集は自動 | 自動 | 確認せず適用（あとで戻せる） | 毎回確認 |

シェルはどのモードでも確認する。作業フォルダの外への書き込みは、どのモードでも確認する。

## 変更の確認と元に戻す
- 編集は差分で見せる。まとまり（hunk）ごとに `y` 採用、`n` 却下、`a` そのファイルは全部採用、`e` 却下して理由を伝える、を選ぶ。却下と理由は、そのままモデルに返す
- やりとりを始める前に、そのやりとりで触るファイルの元の状態を残す（チェックポイント）。`/undo` で直前のやりとりの変更を戻し、`/undo 3` で3つ前まで戻す。git の作業ツリーには手を加えない

## 入力
- 日本語入力（IME）で変換を確定する Enter では送信しない。送信は、変換していない状態での Enter
- 改行は Shift+Enter（端末が区別できないときは `\` のあとに Enter）
- `@` のあとに文字を打つと、作業フォルダのファイルを候補に出す。選んだファイルは中身をそのまま入れず、パスだけを渡してモデルに読ませる（文脈を節約するため）
- Esc で、モデルの返事や道具の実行を止める。2回続けて押すと、直前の入力を書き直せる
- Ctrl+C を2回で終了する

## `/` コマンド（v0.1）
| コマンド | すること |
| --- | --- |
| `/help` | 使い方とキー操作 |
| `/context` | 文脈の内訳（指示、道具の定義、MCP、会話、道具の結果、隠した分）をトークンで見せる |
| `/model` | モデルを切り替える |
| `/mode` | モードを選ぶ（Shift+Tab と同じ） |
| `/undo` | 変更を戻す |
| `/resume` | 保存したセッションの一覧から選んで続ける |
| `/clear` | 会話を空にして始め直す（セッションは保存しておく） |
| `/compact` | 今すぐ会話を要約して短くする |

## セッションの保存
- やりとりの記録を `~/.ja-harness/sessions/<日時>-<作業フォルダ名>.jsonl` に1行ずつ書く。usage と料金も一緒に残す（あとでトークンを測れるように）
- `/resume` と、起動時の `--resume` で続きから始める
