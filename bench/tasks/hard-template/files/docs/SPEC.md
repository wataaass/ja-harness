# テンプレートエンジンの仕様

この文書は、`render(template, data, options)` の動きを決めたもの。
今ある変数の表示と `upper` / `lower` に加えて、条件、繰り返し、
フィルター、エスケープ、include、空白の調整をここに合わせて仕上げる。

## 1. 公開する形

```js
import { render } from "./src/index.js";

const html = render("こんにちは {{ user.name }}", {
  user: { name: "花子" },
});
```

`render(template, data, options)` の形は変えない。

- `template`: テンプレートの文字列。文字列以外は `TypeError`。
- `data`: 変数の元になるオブジェクト。省略すると `{}`。
- `options`: 省略できる。次の値を取る。

| 項目 | 既定 | 意味 |
| --- | --- | --- |
| `templates` | `{}` | include で読む部分テンプレート。名前 → 本文 |
| `escape` | `true` | 変数の出力を HTML エスケープするか |
| `maxIncludeDepth` | `10` | include を入れ子にできる深さ |

戻り値は文字列。

## 2. テンプレートの書き方

テンプレートは、文字と、2種類の印からなる。

- `{{ ... }}`: 値を出力する。
- `{% ... %}`: 条件、繰り返し、include などの命令。

印の外の文字は、そのまま出力する。

## 3. 変数

### 3.1 名前

`{{ name }}` は `data.name` を出す。`{{ user.name }}` のように
ドットで中をたどれる。名前の部分は英字か `_` で始まり、英数字と
`_` を使える。ドットの後ろも同じ。

途中の値が無い場合、`null`、`undefined` の場合、配列の範囲外の
場合は、空文字を出す。エラーにはしない。

```js
render("{{ user.name }}", { user: {} }); // => ""
render("{{ missing }}", {}); // => ""
```

### 3.2 値の表示

- 文字列: そのまま。
- 数: そのまま。`1.5` は `1.5`。
- 真偽値: `true` / `false`。
- `null` と `undefined`: 空文字。
- 配列: 各要素を `, ` でつなぐ。
- オブジェクト: JSON の文字列。

### 3.3 真偽

条件で偽になるのは次の値。

- `false`
- `null` と `undefined`
- `0` と `NaN`
- 空文字
- 空の配列
- キーが無いオブジェクト

それ以外は真。空でない配列、`"0"`、負の数は真になる。

## 4. フィルター

`{{ 値 | 名前 }}` でフィルターを掛ける。`|` は左から順に適用する。

```js
render("{{ name | lower | capitalize }}", { name: "ALICE" });
```

フィルターには引数を渡せる。引数は `(` と `)` の間に `,` で並べる。
引数に使えるのは、文字列、数、`true`、`false`、`null` だけ。

```js
render('{{ title | default("無題") }}', {});
render('{{ tags | join(", ") }}', { tags: ["a", "b"] });
```

### 4.1 一覧

| 名前 | 引数 | 動き |
| --- | --- | --- |
| `upper` | なし | 大文字にする |
| `lower` | なし | 小文字にする |
| `capitalize` | なし | 先頭を大文字、残りを小文字にする |
| `trim` | なし | 前後の空白を落とす |
| `default` | 代わりの値 | `undefined`・`null`・空文字のときだけ代わりを使う |
| `join` | 区切り（既定 `, `） | 配列を文字列につなぐ |
| `truncate` | 長さ | 長い文字列の先頭を切り、`…` を付ける |
| `length` | なし | 文字列・配列・オブジェクトの長さ |
| `replace` | 探す文字、置く文字 | すべて置き換える |
| `escape` | なし | HTML エスケープした印を付ける |
| `safe` | なし | エスケープしない印を付ける |

### 4.2 詳しい決まり

- `default` は `0` と `false` を代わりに置き換えない。
- `join` は配列以外に使うとエラー。区切りを省略すると `, `。
- `truncate` の長さは 0 以上の整数。元の文字列が長さ以下なら変えない。
  長いときは先頭から長さ分を取り、末尾に `…` を付ける。つまり
  結果は長さより1文字長くなる。
- `length` は文字列と配列では要素数、オブジェクトではキーの数、
  それ以外は 0。
- `replace` の置く文字を省略すると空文字にする。
- 知らないフィルター名はエラー。
- フィルターの引数の数や型が違うときもエラー。

## 5. if / elif / else

```html
{% if user.admin %}
  管理者
{% elif user.age >= 18 %}
  一般
{% else %}
  子ども
{% endif %}
```

- `elif` はいくつでも書ける。
- `else` は1つまで。
- `endif` で閉じる。
- 条件は上から順に見て、最初に真になった枝だけを出す。
- どの条件も偽で `else` があれば、その中を出す。
- 条件は「偽」の決まり（3.3）で判定する。

### 5.1 条件に書けるもの

- 値: 文字列、数、`true`、`false`、`null`、`undefined`、名前
- 比較: `==`、`!=`、`<`、`>`、`<=`、`>=`
- つなぐ: `and`、`or`、`not`
- かっこ: `( ... )`

`and` と `or` は短く切る。`not` は直後の条件全体に掛かる。
比較は数どうしなら数の順、それ以外は文字の順で比べる。
`==` は配列やオブジェクトも中身で比べる。

条件にフィルターは書けない。フィルターは出力でだけ使う。

## 6. for

```html
{% for item in items %}
  {{ loop.index }}: {{ item.name }}
{% else %}
  空です
{% endfor %}
```

- `items` は配列。配列以外はエラー。`undefined` と `null` は空として
  扱う。
- 1回ごとに `item` に要素が入る。
- 空の配列のときは `else` の中を出す。`else` は省略できる。
- `endfor` で閉じる。
- `for` の中でも外側の変数が見える。

### 6.1 loop

回の中では `loop` が使える。

| 名前 | 意味 |
| --- | --- |
| `loop.index` | 1 から始まる番号 |
| `loop.index0` | 0 から始まる番号 |
| `loop.first` | 最初の回なら `true` |
| `loop.last` | 最後の回なら `true` |
| `loop.length` | 全体の件数 |

## 7. include

```html
{% include "header" %}
```

`options.templates` から名前で本文を引き、その場所に描く。

```js
render('{% include "header" %}', { title: "家" }, {
  templates: { header: "<h1>{{ title }}</h1>" },
});
```

- 名前は文字列の値で書く。名前以外はエラー。
- 無い名前はエラー。文には名前を入れる。
- include の中でも、呼び出し元と同じ変数が見える。
- include は入れ子にできるが、深さに上限がある。既定は 10。
  上限を超えたらエラー。上限は `maxIncludeDepth` で変えられる。
- 深さは、最初のテンプレートを 0 とし、include するたびに 1 増える。
  `maxIncludeDepth` が 1 なら、include は1回まで。

## 8. HTML のエスケープ

既定では、変数の出力を HTML エスケープする。

| 元 | 変換後 |
| --- | --- |
| `&` | `&amp;` |
| `<` | `&lt;` |
| `>` | `&gt;` |
| `"` | `&quot;` |
| `'` | `&#39;` |

```js
render("{{ name }}", { name: "<b>" }); // => "&lt;b&gt;"
render("{{ name | safe }}", { name: "<b>" }); // => "<b>"
```

- `safe` を通した値は、その後ろで自動エスケープしない。
- `escape` フィルターは、明示的にエスケープした印を付ける。
- `options.escape` が `false` なら、自動エスケープをしない。
- エスケープを2回掛けない。`safe` の値に `escape` を掛けた場合も、
  結果は1回だけエスケープしたものにする。

## 9. 空白の調整

命令のタグでは、開きと閉じに `-` を付けられる。

- `{%-` は、タグの直前の空白（改行を含む）を落とす。
- `-%}` は、タグの直後の空白（改行を含む）を落とす。
- 変数の `{{-` と `-}}` も同じように動く。

```html
{% for item in items -%}
  {{ item }}
{% endfor %}
```

このとき、for の直後の改行と空白が落ちる。`-` を付けない場合は
空白をそのまま残す。

## 10. エラー

テンプレートの誤りは `TemplateError` で投げる。

- `error.name` は `"TemplateError"`。
- `error.line` は、誤りのある行。1 から数える。
- `error.message` の末尾には `（行 N）` を入れる。
- 行番号が分からない誤りでは、`line` は `undefined` でよい。

次の場合はエラーにする。

- タグや変数の印を閉じていない。
- `endif` や `endfor` が無い。
- 知らないタグ、知らないフィルター。
- `if` に条件が無い、`for` の形が違う。
- include の名前が無い、テンプレートが無い。
- include が深すぎる。
- 式に使えない文字がある。

エラーの文は日本語で、何が悪いかを短く伝える。

## 11. しないこと

- 四則演算（`+`、`-`、`*`、`/`）は扱わない。
- 代入や変数の定義は扱わない。
- コメントの記法は扱わない。
- フィルターを条件の中に書くことはできない。
- テンプレートをファイルから読むことはしない。include の本文は
  `options.templates` で渡す。
- ループの中で `break` や `continue` は使えない。

## 12. 例

```js
const templates = {
  row: "<li>{{ loop.index }}. {{ item | capitalize }}</li>",
};

const html = render(
  [
    "<ul>",
    "{% for item in fruits %}",
    '  {% include "row" %}',
    "{% endfor %}",
    "</ul>",
  ].join("\n"),
  { fruits: ["apple", "banana"] },
  { templates },
);
```

この結果は、次のようになる。

```html
<ul>
<li>1. Apple</li>
<li>2. Banana</li>
</ul>
```

## 13. 確認のしかた

`npm test` で、見えているテストを動かす。テストは、仕様の次の点を
確かめる。

- 変数と名前の道、無い値の表示
- `upper` / `lower` と、その連鎖
- `default` / `join` / `truncate` の境界
- `safe` と自動エスケープ、二重エスケープの防止
- `if` / `elif` / `else` の選ばれ方
- `loop.index` / `loop.first` / `loop.last` / `loop.length`
- 空の配列の `else`
- include の変数、入れ子、深さの上限
- `{%-` と `-%}` の空白
- 誤りの行番号

見えているテストはすべてを通すこと。隠したテストでも、この文書に
書いた決まりをすべて確かめる。仕様とテストが食い違うときは、
コードを直す前に、どちらが正しいかを確かめる。

## 14. 用語

- 値: テンプレートに出せるもの。文字、数、真偽値、配列、オブジェクト。
- 名前: `data` の中の値を指す道。`user.name` のように書く。
- フィルター: 値を別の値に変える小さな関数。
- 部分テンプレート: include で読み込む、名前の付いた本文。
- 空白の調整: `-` を付けて、タグの前後の空白を落とすこと。

## 15. モジュールの役割

- `lexer.js`: 文字・変数・タグに分ける。行番号も付ける。
- `parser.js`: 分けたものを木にする。式も読む。
- `ast.js`: 木の形を決める。
- `render.js`: 木を文字にする。
- `filters.js`: フィルターを適用する。
- `escape.js`: HTML のエスケープと、エスケープ済みの印。
- `errors.js`: 行番号つきの誤り。
- `values.js`: 値の読み方と表示。
- `conditions.js`: 条件の評価。
- `loops.js`: for の回の情報。
- `loader.js`: include の本文を引く。
- `index.js`: 公開する関数をまとめる。
