## 2026-10-27: トークン削減で品質が落ちるか（本物の API）

- 課題: `bench/tasks/` の8件（修正4件・生成4件）。採点はモデルに見せないテスト（grade/）が全部通るか
- 条件: `none`（削減なし）・`input-only`（道具の結果を入れる時点で短くする）・`default`（今の既定。input-only に文脈管理を足したもの）

- 実行失敗（モデルが一度も答えないうちに API が失敗した回）は回し直した（MiMo の5回。回し直すと5回とも合格）

### 読み方
- 品質: どのモデルも条件による差は±1回分で、削減のせいで決まって落ちる課題はない。24回では数ポイントの差は見分けられないので、言えるのは「大きくは落ちていない」まで
- 料金: キャッシュの読みが入力の約50分の1のモデル（DeepSeek・MiMo）では11〜17%下がった。約10分の1の Qwen では6〜9%上がった。短くした結果をモデルが読み直す往復が増え（14.6 → 17.5回）、そのたびに文脈を送り直す分が、短くして浮いた分を上回った
- 課題はまだやさしめ（DeepSeek は3条件とも9割以上）。gen-report は MiMo には条件によらず解けない
